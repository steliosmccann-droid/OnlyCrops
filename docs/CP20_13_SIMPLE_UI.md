# Only Crops — Checkpoint 20.13: απλό UI / Κουμπιά

## Τι υλοποιήθηκε
Η οθόνη **Game Maker → Κουμπιά** απέκτησε απλή mobile-first μορφή με επιλογή πραγματικού κουμπιού του παιχνιδιού, τέσσερα μεγάλα βελάκια, βήμα 1/5/10/20 px, ένδειξη θέσης X/Y, επαναφορά θέσης και προαιρετικές προηγμένες ρυθμίσεις.

Ο νέος editor είναι μόνο **interface προς τα υπάρχοντα controls** του V106 Game Maker. Δεν δημιουργεί δεύτερο editor state, δεν προσθέτει κλειδιά αποθήκευσης και δεν αλλάζει το click behavior, τις οικονομικές τιμές, το grid ή τα saves της φάρμας. Οι προηγμένες επιλογές παραμένουν στον υπάρχοντα editor αλλά δεν γεμίζουν την οθόνη του iPhone στην απλή λειτουργία.

## Τρόπος δοκιμής
1. Άνοιξε `https://steliosmccann-droid.github.io/OnlyCrops/?v=cp20.13`
2. Game Maker → Κουμπιά.
3. Επίλεξε π.χ. Select ή Market και πάτησε → μία φορά.
4. Δες εάν μετακινήθηκε το πραγματικό κουμπί. Ανανεώσε την σελίδα και έλεγξε εάν η θέση παρέμεινε.
5. Άνοιξε τις Προηγμένες ρυθμίσεις και έλεγξε τα υπάρχοντα χειριστήρια.

## Έλεγχος
Το νέο JavaScript αρχείο έχει ελεγχθεί ως προς τη σύνταξη. Η συμπεριφορά στο πραγματικό Safari/iPhone χρειάζεται ακόμη επιβεβαίωση.
